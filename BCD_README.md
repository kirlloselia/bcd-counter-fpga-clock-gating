# bcd-counter-fpga-clock-gating

2-digit BCD counter on an Intel FPGA with latch-based clock gating for dynamic power reduction, displayed on onboard 7-segment displays.

---

## Overview

Designed using the Quartus Prime Schematic Editor (Block Diagram/Schematic File), with RTL Verilog auto-generated by Quartus and implemented on an Intel FPGA. The onboard 50 MHz clock is divided to 1 Hz for human-visible counting. Latch-based clock gating suppresses the tens-digit clock until terminal count is reached on the units digit, reducing unnecessary switching activity.

---

## Architecture

| Module | Description |
|---|---|
| `Lab01.v` | Top-level: integrates all submodules |
| `bcd_counter.v` | Single-digit BCD counter (0–9) |
| `clk_divider.v` | Parameterized clock divider (50 MHz → 1 Hz) |
| `clk_gating.v` | Latch-based clock gate for tens digit |
| `d_latch.v` | D-latch used inside the clock gating cell |
| `seg_decoder.v` | BCD to 7-segment decoder |
| `Lab01_tb.v` | Testbench |

---

## How It Works

- The onboard 50 MHz clock is divided by 50,000 to produce a 1 Hz counting clock.
- The **units digit** BCD counter runs on the divided clock continuously.
- The **tens digit** BCD counter receives a gated clock, enabled only when the units digit reaches 9 (terminal count), via a latch-based clock gate to prevent glitches.
- Each digit drives a 7-segment decoder that outputs the active-low segment signals to the FPGA's onboard displays.
